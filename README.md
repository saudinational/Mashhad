# مَشهد | MASHHAD

واجهة أولية عربية لمنصة إعلامية تجمع الصحافة والتحليل والرصد، بهوية داكنة تجمع الأسود والبنفسجي والأبيض.

## الملفات
- `index.html` — بنية الصفحة والأقسام.
- `style.css` — التصميم والتجاوب مع الجوال.
- `script.js` — قائمة الجوال، التاريخ، ونماذج تجريبية.

## تشغيل الموقع
افتح `index.html` في المتصفح، أو ارفع الملفات الثلاثة إلى مستودع GitHub.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا باسم `mashhad` (أو أي اسم تفضله).
2. ارفع `index.html` و`style.css` و`script.js` إلى جذر المستودع.
3. افتح **Settings → Pages**.
4. ضمن **Build and deployment** اختر **Deploy from a branch**.
5. اختر فرع `main` والمجلد `/(root)` ثم اضغط **Save**.
6. انتظر اكتمال النشر، وسيظهر رابط الموقع في صفحة Pages.

## ملاحظات مهمة
- النصوص والأمثلة التحريرية في الواجهة تجريبية وليست أخبارًا حقيقية أو تقارير موثقة.
- الصور مستضافة على Unsplash، والخطوط من Google Fonts؛ يلزم اتصال بالإنترنت لعرضها.
- نموذج التحقق إرشادي فقط، ولا يتصل بخدمة تحقق أو مصادر أخبار.
- نموذج النشرة لا يخزن البريد ولا يرسله إلى أي مكان.
- لا توجد قاعدة بيانات أو نظام تسجيل دخول في هذه النسخة.
- قبل الاستخدام العام، استبدل النصوص التجريبية بمحتوى موثوق، وراجع حقوق استخدام الصور، وأضف سياسة خصوصية وشروط استخدام عند الحاجة.
